


# Courbes d'Apprentissage

🎯 Dans cet exercice, vous couvrirez :

- Les Courbes d'Apprentissage
- Le Biais
- La Variance
- Les Features Polynomiales
- La taille d'entraînement nécessaire

Vous serez guidé à travers l'interprétation des courbes d'apprentissage et la compréhension de comment la complexité du modèle affecte vos résultats et comment vous pouvez prévenir le sous-apprentissage et le surapprentissage.

## Le jeu de données 🏀

Vous plongerez dans le jeu de données NBA. Le jeu de données contient les statistiques de 4000 joueurs NBA, incluant :

- `season` : La saison (annuelle) pendant laquelle le joueur a joué
- `poss` : Possessions jouées
- `mp` : Minutes jouées
- `do_ratio` : Le ratio du temps passé par un joueur en défense vs. en attaque ; les valeurs négatives signifient plus de positionnement en défense
- `pacing` : L'impact du joueur sur les possessions d'équipe par 48 minutes
- `win_rating` : Notation *Wins Above Replacement*, combien de victoires supplémentaires un joueur vaut par rapport à un remplaçant de même niveau

Pour commencer l'exercice, ouvrez `Challenge_Learning_Curves.ipynb` dans `jupyter notebook` et suivez les instructions.
